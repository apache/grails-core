=== Installation

The RxGORM API described in this guide, the `RxEntity` domain model and the RxJava data services, is provided by the `grails-datamapping-rx` module. In a Grails application its version is managed by the Grails BOM:

[source,groovy,subs="attributes"]
.`build.gradle`
----
implementation "org.apache.grails.data:grails-datamapping-rx:{version}"
----

The RxJava data services need nothing more: they run on whichever GORM datastore the application uses. See the RxJava Support section of the Grails user guide.

An `RxEntity` application also needs a datastore implementation of RxGORM, and none ships with this release. The only one that ever existed, RxGORM for MongoDB (`org.grails.plugins:rx-mongodb` in a Grails application, `org.grails:grails-datastore-gorm-rx-mongodb` outside one), was last released for GORM 6.1 on RxJava 1, so it cannot be used with this release unless it is rebuilt against it. Such an implementation is initialised from the bootstrap path of the application through its `RxDatastoreClient`, which takes the connection to the datastore, the name of the default database and the classes that implement link:../api/grails/gorm/rx/RxEntity.html[RxEntity].
