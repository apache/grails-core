=== Where Queries
Where queries are the preferred way to build more complex queries. They are type safe, expressive and lazily executed:

[source,groovy]
----
def query = Book.where {
    title == 'The Stand'
}
----

Note that no query is actually executed directly, instead the `where(Closure)` method returns an instance of link:../api/grails/gorm/rx/DetachedCriteria.html[DetachedCriteria].

The `DetachedCriteria` class is an `io.reactivex.rxjava3.core.ObservableSource`, so it composes with any RxJava 3 operator, for example through `Observable.wrap(..)`. Execute one of its query methods to invoke the query and subscribe to the `io.reactivex.rxjava3.core.Observable` it returns:


[source,groovy]
----
Book.where {
    title == 'The Stand'
}
.findAll()
.subscribe { Book book ->
    println "Title = ${book.title}"
}
----

NOTE: A closure cannot be subscribed to an `ObservableSource` directly, because `io.reactivex.rxjava3.core.Observer` has four methods. Subscribe to the `Observable` a query method returns, as above, or pass the criteria to `Observable.wrap(..)`.

The other query methods invoke the query and return an `io.reactivex.rxjava3.core.Observable` too:


[source,groovy]
----
Book.where { title == 'The Stand' }
    .list()
    .subscribe { List<Book> books ->
        for (Book book in books) {
            println "Title = ${book.title}"
        }
    }
----

For more information on the syntax of where queries see the https://grails.apache.org/docs/latest/grails-data/hibernate5/manual/index.html#whereQueries[relevant section in the GORM documentation].
