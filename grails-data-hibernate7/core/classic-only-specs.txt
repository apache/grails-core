# Specs that run only when the whole suite boots through the classic domain binder:
#   ./gradlew -Pgrails.test.classicDomainBinding=true :grails-data-hibernate7-core:test
#
# The default run boots every manager-built datastore through native domain binding (hibernate.generatedDomainClasses,
# on by default) and EXCLUDES the specs listed here; the classic run runs every spec and does not read this file.
#
# They exercise the classic domain binder or the generator themselves against the classic datastore of the base spec
# (they build binder objects by hand, bind through createPersistentEntity / hibernateFirstPass, or compare the binder
# with the generator), so they need the classic binder to be the one that booted the datastore. A spec is a "binder
# internals" spec when its source lives under cfg/domainbinding or mentions GrailsDomainBinder, GrailsDomainGenerator,
# GeneratedDomainClassBinder, hibernateFirstPass, createPersistentEntity, getGrailsDomainBinder, getCollector(,
# InFlightMetadataCollector or MetadataBuildingContext. Only those that FAIL with a natively bound datastore are listed,
# one fully qualified class name per line; the others run and pass in both modes (every other binder-internals spec,
# the generator differential included, was run against a natively bound datastore before being left out of this list).
# The six listed assert facts of the classic boot model (a collection table the classic binder creates, a unique key it
# drops, the type parameters it sets) or pin classic defects with @PendingFeature, which native binding does not have,
# so they only hold against a classic datastore. The list goes away with the classic binder.
#
