GORM Data Services also support returning RxJava 3 https://reactivex.io/RxJava/3.x/javadoc/io/reactivex/rxjava3/core/Observable.html[io.reactivex.rxjava3.core.Observable] or https://reactivex.io/RxJava/3.x/javadoc/io/reactivex/rxjava3/core/Single.html[io.reactivex.rxjava3.core.Single] types.

To use the RxJava support you need to ensure that the `grails-datamapping-rx` dependency is on the classpath by adding the following to `build.gradle`:

[source,groovy]
.build.gradle
----
implementation "org.apache.grails.data:grails-datamapping-rx"
----

For example:

[source,groovy]
----
import io.reactivex.rxjava3.core.Single

@Service(Book)
interface BookService {
   Single<Book> findOne(String title)
}
----

When a `Single` is used then a single result is returned, and a query that finds nothing signals a `java.util.NoSuchElementException`, since an RxJava 3 `Single` cannot complete without a value. To query multiple results use an `Observable` instead, which completes without emitting when nothing is found:

[source,groovy]
----
import io.reactivex.rxjava3.core.Observable

@Service(Book)
interface BookService {
   Observable<Book> findBooks(String title)
}
----

For regular GORM entities, GORM will by default execute the persistence operation using RxJava's https://reactivex.io/RxJava/3.x/javadoc/io/reactivex/rxjava3/schedulers/Schedulers.html#io--[IO Scheduler].

NOTE: For RxGORM entities where the underlying database supports non-blocking access the database driver will schedule the operation accordingly.

You can run the operation on a different scheduler using the `RxSchedule` annotation:

[source,groovy]
----
import io.reactivex.rxjava3.core.Observable
import io.reactivex.rxjava3.schedulers.Schedulers
import grails.gorm.rx.services.RxSchedule
import grails.gorm.services.Service

@Service(Book)
interface BookService {

   @RxSchedule(scheduler = { Schedulers.newThread() })
   Observable<Book> findBooks(String title)
}
----
