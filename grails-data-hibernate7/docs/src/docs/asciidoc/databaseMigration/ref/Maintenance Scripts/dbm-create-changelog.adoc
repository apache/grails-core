===== dbm-create-changelog

====== Purpose

Creates an empty change log file.

====== Description

Creates a new empty file instead of generating the file from the database (with <<ref-rollback-scripts-dbm-generate-changelog,dbm-generate-changelog>>) or from your GORM classes (with <<ref-rollback-scripts-dbm-generate-gorm-changelog,dbm-generate-gorm-changelog>>).

The folder of the change logs is `grails-app/migrations`, or the one `grails.plugin.databasemigration.changelogLocation` names. Give the name with its extension, which decides the format: `.groovy` for the Groovy DSL, `.xml` for Liquibase XML, and the other formats Liquibase writes, as `.yaml`.

Usage:
[source,console]
----
grails dbm-create-changelog [--add] [--contexts=CONTEXTS] [--dataSource=DATASOURCE] [--defaultSchema=SCHEMA] [--force] FILE
----

Required arguments:

* `FILE` - The change log to create, relative to the folder of the change logs.

Optional arguments:

* `--add` - Adds an `include` of the change log it writes to the root change log.
* `--contexts` - Taken by every tool of the plugin; this one does not use it.
* `--dataSource` - The data source to work with, by its name under `dataSources` in `application.[yml|groovy]`, as `--dataSource=reports`. Without it, the default data source.
* `--defaultSchema` - Taken by every tool of the plugin; this one opens no database and does not use it.
* `--force` - Replaces the change log when it exists; without it the tool fails when the file is there.

The tool runs in the application, which the build of the project starts around it, for the `development` environment. For another environment, name it in front of the name of the tool with `run-tool`, as `grails run-tool -Dgrails.env=production dbm-create-changelog`, or give it to the build, as `./gradlew -Dgrails.env=production runTool --arg=dbm-create-changelog` or `./gradlew -Dgrails.env=production dbmCreateChangelog`; after the name of the tool, `-Dgrails.env` is an argument of the tool and selects no environment.

The value of an option follows `=` or is the next argument: `--dataSource=reports` and `--dataSource reports` are the same. `grails help dbm-create-changelog` lists the options and parameters the tool takes. An option it does not take, an argument more than it takes and a required argument that is missing are refused before the application is started, with exit code 2 and one line, as `| Error dbm-create-changelog: --datasource is not one of its options. grails help dbm-create-changelog shows its options`.
