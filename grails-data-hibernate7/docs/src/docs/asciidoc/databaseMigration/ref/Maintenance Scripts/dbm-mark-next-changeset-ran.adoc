===== dbm-mark-next-changeset-ran

====== Purpose

Marks the next change set as executed in the database.

====== Description

To write the SQL that marks the next change set as executed instead, without updating the database, use <<ref-maintenance-scripts-dbm-mark-next-changeset-ran-sql,dbm-mark-next-changeset-ran-sql>>.

Usage:
[source,console]
----
grails dbm-mark-next-changeset-ran [--contexts=CONTEXTS] [--dataSource=DATASOURCE] [--defaultSchema=SCHEMA]
----

Required arguments: _none_.

Optional arguments:

* `--contexts` - The contexts of the change sets to take, separated by commas: only the change sets of one of them are taken. Without it, the contexts `grails.plugin.databasemigration.contexts` configures, or every change set.
* `--dataSource` - The data source to work with, by its name under `dataSources` in `application.[yml|groovy]`, as `--dataSource=reports`. Without it, the default data source.
* `--defaultSchema` - The schema of the database to work in where the change log names none.

The tool runs in the application, which the build of the project starts around it, for the `development` environment. For another environment, name it in front of the name of the tool with `run-tool`, as `grails run-tool -Dgrails.env=production dbm-mark-next-changeset-ran`, or give it to the build, as `./gradlew -Dgrails.env=production runTool --arg=dbm-mark-next-changeset-ran` or `./gradlew -Dgrails.env=production dbmMarkNextChangesetRan`; after the name of the tool, `-Dgrails.env` is an argument of the tool and selects no environment.

The value of an option follows `=` or is the next argument: `--dataSource=reports` and `--dataSource reports` are the same. `grails help dbm-mark-next-changeset-ran` lists the options and parameters the tool takes. An option it does not take, an argument more than it takes and a required argument that is missing are refused before the application is started, with exit code 2 and one line, as `| Error dbm-mark-next-changeset-ran: --datasource is not one of its options. grails help dbm-mark-next-changeset-ran shows its options`.
