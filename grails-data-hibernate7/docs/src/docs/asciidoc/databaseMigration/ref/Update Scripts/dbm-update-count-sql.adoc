===== dbm-update-count-sql

====== Purpose

Writes the SQL that partially updates the database, to the standard output or a file.

====== Description

Generates the SQL of the given number of the change sets of the change log that have not run, and changes nothing in the database. This is useful for inspecting the generated SQL before running an update, or to generate SQL which can be tuned before running it by hand.

Usage:
[source,console]
----
grails dbm-update-count-sql [--contexts=CONTEXTS] [--dataSource=DATASOURCE] [--defaultSchema=SCHEMA] NUMBER [FILE]
----

Required arguments:

* `NUMBER` - The number of the change sets that have not run to write the SQL of.

Optional arguments:

* `FILE` - The file to write the SQL to, relative to the directory of the project. Without it, the SQL is written to the standard output.
* `--contexts` - The contexts of the change sets to take, separated by commas: only the change sets of one of them are taken. Without it, the contexts `grails.plugin.databasemigration.contexts` configures, or every change set.
* `--dataSource` - The data source to work with, by its name under `dataSources` in `application.[yml|groovy]`, as `--dataSource=reports`. Without it, the default data source.
* `--defaultSchema` - The schema of the database to work in where the change log names none.

The tool runs in the application, which the build of the project starts around it, for the `development` environment. For another environment, name it in front of the name of the tool with `run-tool`, as `grails run-tool -Dgrails.env=production dbm-update-count-sql`, or give it to the build, as `./gradlew -Dgrails.env=production runTool --arg=dbm-update-count-sql` or `./gradlew -Dgrails.env=production dbmUpdateCountSql`; after the name of the tool, `-Dgrails.env` is an argument of the tool and selects no environment.

The value of an option follows `=` or is the next argument: `--dataSource=reports` and `--dataSource reports` are the same. `grails help dbm-update-count-sql` lists the options and parameters the tool takes. An option it does not take, an argument more than it takes and a required argument that is missing are refused before the application is started, with exit code 2 and one line, as `| Error dbm-update-count-sql: --datasource is not one of its options. grails help dbm-update-count-sql shows its options`.
