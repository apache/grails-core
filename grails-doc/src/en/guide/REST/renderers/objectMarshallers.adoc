Grails' converters, `grails.converters.JSON` and `grails.converters.XML`, feature the notion of an link:{api}org/grails/web/converters/marshaller/ObjectMarshaller.html[ObjectMarshaller] and each type can have a registered `ObjectMarshaller`. You can register custom `ObjectMarshaller` instances to completely customize response rendering. For example, you can define the following in `BootStrap.init`:

[source,groovy]
----
XML.registerObjectMarshaller Book, { Book book, XML xml ->
  xml.attribute 'id', book.id
  xml.build {
    title(book.title)
  }
}
----

NOTE: JSON `ObjectMarshaller` registration remains supported for `render ... as JSON` and legacy
converter-based `respond`. Registration does not change `grails.web.rendering.json.spring`, which
defaults to `false` in Grails 9. For Spring-based rendering, register Jackson serializers through
Spring Boot's `JsonMapperBuilderCustomizer`. Named/default JSON converter configuration APIs are
deprecated and scheduled for removal in Grails 11; use `NamedJsonConfigurationRegistry` instead.
XML marshalling requires `org.apache.grails:grails-xml`, which the Grails web starter and `grails-web-boot` bring in
Grails 9, and which needs a dependency of its own from Grails 10. Legacy XML conversion is scheduled for removal in Grails 11.

You can customize the formatting of an individual value this way too. For example, the https://grails-plugins.github.io/grails-joda-time/index.html[JodaTime plugin] does the following to support rendering of JodaTime dates in JSON output:

[source,groovy]
----
JSON.registerObjectMarshaller(DateTime) {
    return it?.toString("yyyy-MM-dd'T'HH:mm:ss'Z'")
}
----

In the case of JSON it's often simple to use a map to customize output:

[source,groovy]
----
JSON.registerObjectMarshaller(Book) {
  def map= [:]
  map['titl'] = it.title
  map['auth'] = it.author
  return map
}
----


Jackson serializers, which Spring MVC, `respond` and `render json:` write with, and named Jackson configurations are
described in <<jacksonJson,Customizing JSON With Jackson>>.
