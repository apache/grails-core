No direct support is provided for RSS or Atom within Grails. You could construct RSS or ATOM feeds with the link:{controllersRef}render.html[render] method's XML capability. The Atom renderers in the `grails.rest.render.atom` package are part of the `grails-xml` module, which the Grails 9 web starter and `grails-web-boot` bring, and are registered explicitly as renderer beans. They extend the HAL XML renderer and, like it, are deprecated for removal in Grails 11; write new feeds with a view or an application renderer.
