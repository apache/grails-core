Plugins can easily provide their own artefacts so that they can easily find out what implementations are available and take part in reloading. All you need to do is create an `ArtefactHandler` implementation in the plugin's sources:

[source,groovy]
----
package org.somewhere

import grails.core.ArtefactHandlerAdapter

class MyArtefactHandler extends ArtefactHandlerAdapter {
    ...
}
----

The Grails compiler registers every concrete `ArtefactHandler` written in Groovy in the `META-INF/grails.factories` file it writes beside the compiled classes, under the `grails.core.ArtefactHandler` key, and the application loads every handler that the `grails.factories` files on its class path list. The plugin class does not list its handlers. A handler written in Java, which the Grails compiler does not see, is registered by hand in `src/main/resources/META-INF/grails.factories`, whose entries the compiler merges with the ones it writes:

[source,properties]
----
grails.core.ArtefactHandler=org.somewhere.MyArtefactHandler
----

So, what does an artefact handler look like? Well, put simply it is an implementation of the link:{api}grails/core/ArtefactHandler.html[ArtefactHandler] interface. To make life a bit easier, there is a skeleton implementation that can readily be extended: link:{api}grails/core/ArtefactHandlerAdapter.html[ArtefactHandlerAdapter].

In addition to the handler itself, every new artefact needs a corresponding wrapper class that implements link:{api}grails/core/GrailsClass.html[GrailsClass]. Again, skeleton implementations are available such as link:{api}org/grails/core/AbstractInjectableGrailsClass.html[AbstractInjectableGrailsClass], which is particularly useful as it turns your artefact into a Spring bean that is auto-wired, just like controllers and services.

The best way to understand how both the handler and wrapper classes work is to look at the Quartz plugin:

* https://github.com/apache/grails-quartz/blob/master/src/main/groovy/grails/plugins/quartz/GrailsJobClass.java[GrailsJobClass]
* https://github.com/apache/grails-quartz/blob/master/src/main/groovy/grails/plugins/quartz/DefaultGrailsJobClass.java[DefaultGrailsJobClass]
* https://github.com/apache/grails-quartz/blob/master/src/main/groovy/grails/plugins/quartz/JobArtefactHandler.groovy[JobArtefactHandler]

Another example is the https://github.com/nerdErg/grails-shiro[Shiro plugin] which adds a realm artefact.
