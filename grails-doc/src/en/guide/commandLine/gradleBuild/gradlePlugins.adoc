Use `grails create-app myapp` to generate a project; application generation options such as `--jdk` and `--data` are options of that command.

When you create a new project with the link:{commandLineRef}create-app.html[create-app] command (`grails create-app`), a default `build.gradle` is generated for you.

[source,groovy]
----
plugins {
    id "groovy"
    id "war"
    id "idea"
    id "eclipse"
}

apply plugin: "cloud.wondrify.asset-pipeline"
apply plugin: "org.apache.grails.gradle.grails-web"
apply plugin: "org.apache.grails.gradle.grails-gsp"
----

The default plugins are as follows:

* `groovy` - The Groovy plugin adds support for Groovy projects. It can handle Groovy code mixed with Java. Read More: https://docs.gradle.org/{gradleVersion}/userguide/groovy_plugin.html[The Groovy Plugin]
* `war` - The https://docs.gradle.org/{gradleVersion}/userguide/war_plugin.html[WAR plugin] changes the packaging so that Gradle creates a WAR file. You can comment out this plugin to build a runnable JAR file for standalone deployment.
* `idea` - The IDEA plugin generates files used by https://www.jetbrains.com/idea/[IntelliJ IDEA], allowing the project to be opened from IDEA. Read More: https://docs.gradle.org/{gradleVersion}/userguide/idea_plugin.html[The IDEA Plugin]
* `eclipse` - The Eclipse plugins generate files for the https://eclipseide.org/[Eclipse IDE], enabling project import (File - Import... - Existing Projects into Workspace). Read More: https://docs.gradle.org/{gradleVersion}/userguide/eclipse_plugin.html[The Eclipse Plugin]
* `asset-pipeline` - The https://github.com/wondrify/asset-pipeline[Asset Pipeline] plugin enables compilation of static assets (JavaScript, CSS, etc.)

Many of these are built-in plugins provided by Gradle or third-party plugins. The Gradle plugins that Grails provides are as follows:

* `org.apache.grails.gradle.grails-app` - Marks the project as a Grails application
* `org.apache.grails.gradle.grails-docs` - Adds Grails doc publishing support
* `org.apache.grails.gradle.grails-gsp` - Adds support for compiling Groovy Server Pages (GSP)
* `org.apache.grails.gradle.grails-gson` - Adds support for compiling JSON Views (GSON)
* `org.apache.grails.gradle.grails-markup` - Adds support for compiling Markup Views (XML)
* `org.apache.grails.gradle.grails-cli` - Configures the tools of the project: the source sets `cli` (`src/cli`) and `standalone` (`src/standalone`), the scopes `grailsCli` and `grailsCliStandalone` with the automatic discovery of the `-cli` and `-cli-standalone` companions of plugins, the task `runTool` and the task of each tool of a plugin, the tool catalog, and the console/shell tasks; applied automatically by the application and plugin plugins
* `org.apache.grails.gradle.grails-plugin` - Marks the project as a Grails plugin
* `org.apache.grails.gradle.grails-plugin-cli` - Publishes the tools of a plugin as the companion artifacts `-cli` (`src/cli`) and `-cli-standalone` (`src/standalone`), each when its folder has a tool, keeping tools off application runtime classpaths; applied automatically by the plugin plugin, and applied by hand to a project that is no Grails plugin
* `org.apache.grails.gradle.grails-web` - Adds the web URL mappings report to the Gradle project
* `org.apache.grails.gradle.grails-publish` - Assists in publishing to Maven or Nexus repositories
