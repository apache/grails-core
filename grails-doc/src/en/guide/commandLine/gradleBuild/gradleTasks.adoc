As mentioned previously, the commands of `grails` that build, test or run a project run the Gradle wrapper of the project. The following table shows which Gradle tasks a command runs:

[format="csv", options="header"]
|===

*Grails Command*,*Gradle Task*
clean,clean
compile,classes
assemble (also war and package),assemble
run-app,bootRun
test-app,test and integrationTest
test-app --unit,test
test-app --integration,integrationTest
console,console
shell,shell
run-tool (also run-command),runTool (also runCommand)
run-script (deprecated),runScript (deprecated)
dependency-report,dependencies
package-plugin,jar
publish-plugin,publish
|===

You can run any of these tasks with the Gradle wrapper of the project if you prefer:

[source,bash]
----
$ ./gradlew test
----

Any other task is run with the wrapper too, or with the `gradle` command of `grails`, which runs the wrapper of the project the current directory is in and gives it every argument as it is:

[source,bash]
----
$ grails gradle compileGroovy
----

The `gradle` command can be given in link:commandLine.html#interactiveMode[interactive mode] as well:

[source,bash]
----
$ grails
grails> gradle compileGroovy
 ...
----

To find out what Gradle tasks are available, use the Gradle `tasks` task:

[source,bash]
----
$ ./gradlew tasks
----
