When you execute the `grails` command without a command in a Grails project, the command line enters interactive mode. In this mode it functions like a shell, allowing you to run multiple commands without starting the command line again for each. This is particularly useful when working with code-generation commands (such as `create-controller`) or exploring what the command line has.

[source,console]
----
$ cd myapp
$ grails
grails> create-controller Book
grails> create-domain-class Book
grails> exit
----

Outside a project, `grails` without a command shows the help, and with `--non-interactive` it shows the help everywhere.

* Every command of the current directory can be given at the prompt, with its options, as it is given after `grails` on the command line. A line that starts with `#` is ignored.
* `exit` leaves interactive mode, as do the end of the input (Ctrl-D) and the interrupt of the terminal (Ctrl-C) at the prompt. Ctrl-C while a command runs Gradle stops Gradle and returns to the prompt.
* `run-app` returns to the prompt once the application answers on its port and leaves it running, so that other commands can be given; `stop-app` stops it. See link:commandLine.html#gradleBuild[Building with Gradle].

NOTE: The interactive mode of the Grails shell of earlier versions had the commands `open`, which opened a file with the program of the desktop, `quit`, and `!`, which ran a program of the operating system or repeated the last command. Interactive mode has none of them: `exit` leaves it, and a file is opened and a program is run in another terminal. Its prompt is `grails>`, and it does not say `Enter a command name to run. Use TAB for completion:` when it starts. See "Commands of Earlier Versions" in xref:commandLine[The Command Line].

One of the advantages of interactive mode is the availability of tab-completion. You can simply press the TAB key to view possible options for a given command or flag. The commands that are completed are those of the current directory as it is after the last command: once a command has made the directory a project, or has added a feature that brings a command, the commands of the project are completed without leaving interactive mode.

== Help and Information

You can access general usage information for Grails commands using the help flag associated with a specific command, or with the `help` command followed by the name of the command (`help create-app`); `help` alone lists the commands. The names of commands can be shortened in interactive mode as on the command line: `cA` is `create-app` there too.

----
grails> create-app -h
