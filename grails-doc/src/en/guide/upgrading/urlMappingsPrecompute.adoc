=== URL mapping precomputation seed

Grails 8.0 starts reserving and detecting `META-INF/grails/url-mappings-index.properties` as the build-time URL mappings index location.
The descriptor is not yet used to alter matching, so the existing runtime mapping evaluation path remains authoritative whether or not a descriptor is packaged.

This is a first compatibility slice only.
Applications do not need to generate the descriptor yet, and existing `UrlMappings.groovy` behavior remains authoritative until a later release wires a complete build-time index generator.
