== Commands

The plugin has two commands. They only write files of the project, so the `grails` command line starts each as a Java process of its own, without Gradle and without the application (they are standalone commands, see xref:commandLine#creatingCustomCommands[Creating Custom Commands]), so the project need neither compile nor be able to start. `grails run-command` and the Gradle task `runCommand` run them with the build, which compiles the project first.

[source,bash]
----
./gradlew runCommand -Pargs="s2ui-override user com.yourcompany.yourapp"
----

The `grails` command runs the same task: `grails s2ui-override user com.yourcompany.yourapp`, or `grails run-command s2ui-override user com.yourcompany.yourapp`.

Up to Grails 8 the two were scripts of the plugin, which the Grails shell ran by their names, as in `grails s2ui-override user com.yourcompany.yourapp`. The commands take the same arguments and write the same files; the Gradle task `runScriptCommand`, which ran the scripts in earlier builds of Grails 9, does not run them any more.
