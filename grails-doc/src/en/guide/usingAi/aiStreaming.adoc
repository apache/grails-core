A model answers token by token, and a client that shows the tokens as they arrive feels far faster than one that waits for the whole answer. The `ChatClient` streams through `stream()`, which returns a Reactor `Flux`, and a Grails controller action can return that `Flux` directly:

[source,groovy]
.grails-app/controllers/my/app/ChatController.groovy
----
package my.app

import org.springframework.ai.chat.client.ChatClient

class ChatController {

    ChatClient.Builder chatClientBuilder

    def ask(String question) {
        chatClientBuilder.build()
                .prompt()
                .user(question)
                .stream()
                .content()
    }
}
----

Grails handles the request asynchronously, commits the response as `text/event-stream` and writes every item the `Flux` emits to the client as a server-sent event, so the text of the answer arrives as the model produces it, and ends the response with an event named `complete` that the client closes on; should the model fail part way, the stream still ends with that event, its data then being `error`. Returning `stream().chatResponse()` works as well: the plugin renders each chat response as the text it carries. A browser reads the events with `EventSource`:

[source,javascript]
----
const answer = document.getElementById('answer');
const source = new EventSource('/chat/ask?question=' + encodeURIComponent(question));
source.onmessage = event => { answer.textContent += event.data; };
source.addEventListener('complete', () => source.close());
----

This is the general streaming support of Grails, which any Reactive Streams `Publisher` returned from an action gets; the <<asyncStreaming,Streaming Responses>> section of the asynchronous programming chapter describes the event format, how other kinds of item are rendered and the `grails.async.streaming` settings. A stream has no timeout unless `grails.async.streaming.timeout` sets one, so a slow or reasoning model that takes minutes to answer is not cut off; set it to bound how long an answer may take:

[source,yaml]
.grails-app/conf/application.yml
----
grails:
    async:
        streaming:
            timeout: 5m
----

A `Mono`, such as `stream().content().collect(...)` or the result of a single call, is not streamed: it is resolved, and its value is the action's result as a returned `Promise`'s value is.
