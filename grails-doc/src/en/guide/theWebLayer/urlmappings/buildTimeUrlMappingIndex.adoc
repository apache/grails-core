Grails writes a URL mapping index while a project is built.
The application gets one index, and each plugin gets its own, because URL mappings come from both.
The index is generated into that project's classpath root at `META-INF/grails/url-mappings.index`.
It is not a file to create or edit by hand.

At runtime Grails still evaluates the `UrlMappings` classes and matches requests with those mappings.
An index entry is used only when it names the same pattern, controller, action, namespace, and plugin as the mapping that evaluation produced.
A field the index leaves out does not stand in for a value that mapping has.
A missing index, a stale entry, or an index that cannot be read leaves that match on the evaluated mappings.
An application or plugin with no constant mappings still ships the index, with `mapping.count=0`.

The file is UTF-8 properties.
`format.version` is `1`.
`artifact.type` is `application` or `plugin`, and `artifact.name` is the application or plugin name.
`mapping.count` is the number of constant mappings that were written.
Each mapping is `mapping.<n>.pattern`, `mapping.<n>.controller`, `mapping.<n>.action`, and, when the mapping states them, `mapping.<n>.method`, `mapping.<n>.namespace`, `mapping.<n>.plugin`, and `mapping.<n>.view`.

[source,properties]
----
format.version=1
artifact.type=application
artifact.name=my-app
mapping.count=1
mapping.0.pattern=/books
mapping.0.controller=book
mapping.0.action=list
----
