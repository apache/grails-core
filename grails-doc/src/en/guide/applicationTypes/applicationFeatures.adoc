A feature is one thing an application can have: a database driver, a view technology, a plugin with its configuration, a servlet container, a workflow for continuous integration. A feature adds what the application needs for it: dependencies and plugins in `build.gradle`, settings in `application.yml`, files.

Every `create-` command lists the features of its type of application with `--list-features`. The ones the application has without being asked for are marked `(+)`:

[source,console]
----
$ grails create-app --list-features
$ grails create-restapi --list-features
----

Features are chosen when the project is created:

[source,console]
----
$ grails create-app com.example.shop --features postgres --exclude-features mockito
----

* `--features` adds features to the default ones. A feature brings in the features it requires, and a feature that takes the place of a default one, as `postgres` takes the place of `h2`, leaves that one out.
* `--exclude-features` leaves out features the project would have by default.
* The Grails Data implementation, the servlet container, the reloading and the JDK have options of their own: `--data`, `--servlet`, `--reloading` and `--jdk`.
* Features that cannot be had together, and a name that is no feature of the type of application, are refused, and nothing is created.

The features a project was created with are recorded in its `.grails` directory, with the options and the type. With that record a feature can be added later, and the project can be shown and generated again:

[source,console]
----
$ cd shop
$ grails feature add grails-quartz
$ grails project show
$ grails project regenerate --diff
----

`feature add` changes the files of the project to what the `create-` command would have written with the feature, and keeps the changes you made. `project show` says how the project was generated and prints the command that creates it again. `project regenerate` writes the project as it was generated to another directory, or names the files that are no longer as they were generated. See "The `.grails` directory of a project", "How a project was generated, and generating it again" and "Adding a feature to a project" in xref:commandLine#creatingProject[Creating a Grails Project]. An application that has no such record, as one of an earlier version, is given one by `project migrate`, for the commands that create its classes; a feature is not added to such an application by `feature add`. See "The record of an application that was not generated by Grails 9" in the same section.
