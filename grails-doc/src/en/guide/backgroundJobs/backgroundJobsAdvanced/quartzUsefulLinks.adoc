The plugin is a thin, convention-driven layer over Quartz itself. When you need detail the guide does not cover — the full cron syntax, the trigger types, job-store and clustering configuration — the Quartz documentation is the authority.

* https://www.quartz-scheduler.org/[Quartz Enterprise Job Scheduler] — the project home page.
* https://www.quartz-scheduler.org/documentation/[Quartz documentation] — tutorials, configuration reference, and cookbook.
* https://www.quartz-scheduler.org/documentation/quartz-2.3.0/tutorials/tutorial-lesson-02.html[Jobs and triggers] — how Quartz models the two, and the trigger types available.
* https://www.quartz-scheduler.org/api/2.5.0/org/quartz/CronExpression.html[`CronExpression`] — the complete cron expression syntax, including the special characters.
* https://www.quartz-scheduler.org/documentation/quartz-2.3.0/configuration/[Quartz configuration reference] — every `org.quartz.*` property that can be set through the `quartz` block described in <<quartzConfiguration,Configuration>>.
* https://www.quartz-scheduler.org/api/2.5.0/[Quartz API documentation].
