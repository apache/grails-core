The `grails` command has an interactive mode, in which commands are given one after the other without starting the command line again for each. To use it, type `grails` without a command in the directory of a project:

[source,console]
----
$ cd myapp
$ grails
grails>
----

At the prompt, the TAB key completes the names of commands and options and lists the ones there are. Every command that can be given after `grails` can be given at the prompt:

[source,console]
----
grails> create-controller greeting
grails> run-app
----

`exit` or `quit` leaves interactive mode. Outside a project, `grails` without a command shows the help.

For more information on the capabilities of interactive mode, refer to the section on link:commandLine.html#interactiveMode[Interactive Mode] in the user guide.
