== cspNonce



=== Purpose


Renders the nonce of the request's nonce-based Content Security Policy, for the `nonce` attribute of an inline script or style.


=== Examples


[source,xml]
----
<script nonce="${g.cspNonce()}">
    document.getElementById('greeting').textContent = 'Hello'
</script>

<style nonce="<g:cspNonce/>">
    #greeting { font-weight: bold }
</style>
----


=== Description


A policy configured with `grails.security.headers.content-security-policy.value` names the nonce with the `+{nonce}+` placeholder, for example `script-src 'self' 'nonce-+{nonce}+'`.
Each request then carries a nonce of its own, which this tag renders, and the policy the response carries names the same nonce.
See link:{guidePath}/security.html[Security] for configuring the policy.

The tag renders the nonce Spring Security's `ContentSecurityPolicyNonceGeneratingFilter` generated when that filter put one on the request, so it can be used with a policy Spring Security writes as well.

It renders nothing when the request carries no nonce.

The tag works in a statically compiled page as well as a dynamic one. Code outside a view, such as a controller, reads the nonce with `ContentSecurityPolicyNonce.nonceOf(request)` from the `grails.web.http` package.
