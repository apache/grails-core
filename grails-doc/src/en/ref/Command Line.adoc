=== Command Line Usage


Grails has one command line, the `grails` command, and incorporates the powerful build system https://gradle.org[Gradle].

The basic usage scenario is:

[source,console]
----
grails <<command name>> <<options>>*
----

`grails help` lists the commands there are in the current directory: outside a project the commands that create one, and in a project also the commands that create its classes, the tools of the application and its plugins, and the scripts in `src/main/scripts` of the project. `grails help NAME` shows how the command `NAME` is used.

The commands that run the build of a project take the environment after their name, either with one of the built-in environment names or with one of your own:

[source,console]
----
grails run-app -Dgrails.env=test
grails assemble -Dgrails.env=uat
----

The same goes for the Gradle tasks those commands run:

[source,console]
----
./gradlew bootRun -Dgrails.env=test
./gradlew bootRun -Dgrails.env=custom
----

An environment in front of the command, as in `grails test run-app` of earlier versions, is refused: what follows `grails` is the name of a command.

Refer to the user guide section on link:{guidePath}commandLine.html[The Command Line] for more information.
