== plugin show

=== Purpose

Says what is known of one Grails plugin: its versions, what it is for, its license, where its documentation, issues and sources are, and the line that adds it to the build of an application. It is the link:plugin-info.html[plugin-info] command by its name among the commands of `plugin`, and `plugin info` is another name of it.

=== Examples

[source,console]
----
grails plugin show cache
grails plugin info cache
grails plugin show org.apache.grails:grails-cache
grails plugin show audit-logging --snapshots
grails plugin show cache --json
----

=== Description

Usage:

[source,console]
----
grails plugin show [--snapshots] [--offline] [--json] [--plugin-index=URL] PLUGIN
grails plugin info [--snapshots] [--offline] [--json] [--plugin-index=URL] PLUGIN
----

`plugin show`, `plugin info` and link:plugin-info.html[plugin-info] are one command with three names: the argument, the options, what is written, the JSON document of `--json` and the exit codes are those of `plugin-info`, which that page describes. None of the names is deprecated. The one difference is the command that is named for the list of the plugins when a plugin is not known, which is link:plugin-list.html[plugin list]:

[source,console]
----
$ grails plugin show no-such-plugin --offline
| Error No plugin no-such-plugin is known among the plugins of this release of Grails. grails plugin list lists the plugins, and a plugin that is in neither list is looked for in the repositories when it is given by its coordinates, as group:artifact
----

On the TAB key, the interactive console and the completion script complete the artifacts of the plugins of this release of Grails after `plugin show` and `plugin info`, as after `plugin-info`.
