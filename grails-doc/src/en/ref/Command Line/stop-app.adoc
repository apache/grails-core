== stop-app



=== Purpose


Stops a Grails application that was started with the link:{commandLineRefFromRef}run-app.html[run-app] command.

NOTE: This command works in development mode only.


=== Examples


[source,groovy]
----
$ grails
grails> run-app
grails> stop-app
----

It can also be run as a separate invocation, including from a different terminal than the one that started the application:

[source,bash]
----
$ grails stop-app
----


=== Description


Use `stop-app` to stop the application for the current project after it has been started with `run-app`. The command can be run from interactive mode or as a separate command from another terminal.

On Linux and macOS the application is shut down gracefully, so JVM shutdown hooks and Spring's orderly shutdown run. On Windows the application is terminated on a best-effort basis and a graceful shutdown is not guaranteed.

If no application started by `run-app` is running for the project, `stop-app` reports that the application is not running.


=== Grails Forge CLI


In the Grails Forge CLI, `stop-app` ends the application that `run-app` of the Grails Forge CLI started for the project, with the Gradle that ran it, and nothing else: it goes by the record `run-app` wrote to `.grails/run/app.json` and ends a process only when it is the recorded one, by its number, the instant it began, its user and its command line. It waits until nothing answers on the port of the application any more before it says that the application stopped. It does not stop an application that the `grails` shell or `gradlew bootRun` started. Without a running application it says so and ends with exit code 1. See the user guide section on link:{guidePath}commandLine.html#gradleBuild[Gradle] for the details.
