== create-script

=== Purpose

The `create-script` command creates a Grails code generation script, which is then a command of the project by the name of its file.

NOTE: Script commands are deprecated. Write a new command as a class of the application with link:create-command.html[create-command].

=== Examples

[source,console]
----
grails create-script my-script
----

Creates a script called `src/main/scripts/my-script.groovy` such as:

[source,groovy]
----
description "Example description", "grails example-usage"

println "Example Script"
----

The script can then be run with:

[source,console]
----
grails my-script
----

=== Description

Usage:

[source,console]
----
grails create-script [-f] <<name>>
----

Writes `src/main/scripts/<name>.groovy` from the template `artifacts/Script.groovy`, with the name in lower case and with hyphens whichever way it is given: `create-script DataImport` and `create-script data-import` both write `data-import.groovy`. A script has no package, so a name with a dot is refused, and its name has only the letters a to z and digits, in words that capitals or hyphens set apart. When the file is there already the command writes nothing and ends with exit code 1, unless `-f` or `--force` is given. The template is text with the tokens the other templates have, such as `@artifact.name@`; it is not run as a Groovy template.

The script is run by the build of the project, through the Gradle task `runScriptCommand`, and not by the `grails` command itself. It has methods for generating code from templates and for working with files, and can call another script as a method; it cannot run Gradle tasks (the `gradle` property) or commands that are no scripts, such as `testApp()`. See link:{guidePath}commandLine.html#creatingCustomScripts[Creating Custom Scripts] for what a script has, and "Creating Classes with the `grails` Command" in link:{guidePath}commandLine.html[The Command Line] for the names the command takes and how a project replaces the template.
