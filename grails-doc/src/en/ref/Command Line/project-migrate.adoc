== project migrate

=== Purpose

Writes the record of the application in the current directory, for an application that has none: one that was created with the Grails shell, one that an earlier version generated, or one that was not generated at all. The `create-*` code generation commands are there once the application has the record.

=== Examples

[source,console]
----
grails project migrate
grails project migrate --dry-run
grails project migrate com.example.shop --type rest-api --features grails-quartz
grails project migrate --force --exclude-features postgres
----

=== Description

Usage:

[source,console]
----
grails project migrate [<<name>>] [--type=<<type>>] [--features=<<feature>>[,<<feature>>...]] [--exclude-features=<<feature>>[,<<feature>>...]]
                    [--jdk=<<version>>] [--servlet=<<servlet>>] [--data=<<data>>] [--reloading=<<reloading>>] [--dry-run] [--force]
----

Arguments:

* `name` - The name of the application, as a `create-` command takes it: with its package in front, as `com.example.shop`, for the package its classes are created in, or alone.

Options:

* `--type=TYPE` - The type of the application: `web` (what `create-app` creates), `rest-api`, `plugin`, `web-plugin` or `rest-api-plugin`.
* `--features=FEATURE[,FEATURE...]` - Features the application has besides those that were found, by the names the `create-` commands list with `--list-features`.
* `--exclude-features=FEATURE[,FEATURE...]` - Features the application does not have, to leave out of those that were found.
* `--jdk=VERSION`, `--java-version` - The version of Java the application is for.
* `-s`, `--servlet=SERVLET` - The servlet implementation the application has: `tomcat`, `jetty`, `undertow` or `none`.
* `-d`, `--data=DATA` - The Grails Data implementation the application has: `hibernate5`, `hibernate7`, `mongodb` or `neo4j`.
* `-r`, `--reloading=RELOADING` - How the application reloads in development: `devtools`, `jrebel` or `none`.
* `--dry-run` - Say what the record would be, and write nothing.
* `--force` - Write the record again over one this command wrote, worked out anew: the name and the options that were given before are given again. The record of how an application was generated is never replaced.

`project migrate` is the `migrate` command of the `project` command. It reads the files of the project as text and runs nothing of the build: the `grails-forge-cli.yml` (or `grails-cli.yml`) of an earlier version, `grails.profile` and `grails.codegen.defaultPackage` in `grails-app/conf/application.yml`, the `profile` dependency, the Grails Gradle plugins, the `group` and the dependencies of `build.gradle`, `rootProject.name` in `settings.gradle`, and the package of the `Application` class. A project whose build is written in Kotlin is read from `build.gradle.kts` and `settings.gradle.kts`. A dependency is found where it is written as `implementation "group:name"` or as `implementation group: 'group', name: 'name'`, and not in a comment. It says what it found, where it found it and what it assumed, and also what it knows it did not read: a build file that `build.gradle` applies, a dependency of a version catalog, what `build.gradle` declares for other projects, and, for a project without a `settings.gradle` of its own, the build above it. The options and the name say it otherwise.

It writes the files of the record in the `.grails` directory (`project.yml`, `forge.lock.yml` and `baseline/index.yml`, and `.gitignore` and `.gitattributes` when they are not there) and no other file of the project. The record has `generationState: untracked` and a baseline without files. link:feature-add.html[feature add] and link:project-regenerate.html[project regenerate] refuse such an application and change nothing; link:project-show.html[project show] shows the record.

The command refuses, with exit code 1 and without writing anything, a project that has the record of how it was generated, what is left of a record that is not complete or cannot be read, and a project whose type or package it cannot work out. A type, a feature or a version of Java that is none is a mistake in the command line, with exit code 2.

See "The record of an application that was not generated by Grails 9" in link:{guidePath}commandLine.html#creatingProject[Creating a Grails Project] for the details.
