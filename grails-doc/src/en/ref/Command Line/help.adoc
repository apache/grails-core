== help

=== Purpose

Displays Grails command line help

=== Examples

[source,console]
----
grails help
grails help run-app
grails help feature add
grails create-app --help
grails help --json
----

=== Description

Usage:

[source,console]
----
grails help [--json] [<<command name>>...]
----

Arguments:

* `command name` - The command to display help for. For a command of a command give both names, as in `help feature add`.

Options:

* `--json` - Write the commands there are in the current directory, with their options, as one JSON document for a tool to read.

Without a command, `help` shows how the command line is used and lists the commands there are in the current directory, with the first sentence of the description of each. Outside a project those are the commands that create one and the commands that run a build; in a project there are also the commands that create its classes, those of the command line and those a feature of the project gives it, and the commands of the application and its plugins:

[source,console]
----
$ grails help
Usage: grails [-hvVx] [--non-interactive] [--plain-output] [COMMAND]
...
Options:
  -h, --help              Show this help message and exit.
      --non-interactive   Never wait for what a user types: without a command the help is shown and
                            the interactive console is not started, and a command that reads what
                            is typed is refused.
      --plain-output      Write plain text for a program to read: no colour or other terminal
                            markup, and no progress display of Gradle.
  -v, --verbose           Create verbose output.
  -V, --version           Print version information and exit.
  -x, --stacktrace        Show full stack trace when exceptions occur.

Commands:
  create-app              Creates an application
  create-webapp           Creates an application; another name of create-app
  create-plugin           Creates a Grails plugin
  create-web-plugin       Creates a Grails plugin with a web layer
  create-rest-api-plugin  Creates a Grails plugin with a REST API
  create-restapi          Creates a REST API application
  feature                 Works with the features of the application in the current directory
...
----

`help` runs nothing to answer, also for a command of the application or of a plugin, or a script of the application: it describes those from what the build of the project listed of them, with where each comes from and how it is run, and starts neither the build nor the command.

Every command of `grails` itself also shows how it is used when it is given `--help` (`-h`): `grails create-app --help` is `grails help create-app`. A command that gives everything after its name to something else does not: `help gradle` is how to see the help of the link:gradle.html[gradle] command itself, since `gradle --help` is given to Gradle, and `NAME --help` for a command of the application or of a plugin gives `--help` to that command and runs it through the build of the project, so `grails help NAME` is the way to ask about such a command. A command there is not ends `help` with exit code 2.

See "Help" in link:{guidePath}commandLine.html[The Command Line] for the JSON document.
