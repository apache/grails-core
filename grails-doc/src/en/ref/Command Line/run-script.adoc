== run-script

=== Purpose

Execute Groovy script(s) in the context of a Grails environment.

WARNING: Groovy scripts intended to be executed this way cannot be located in `src/main/scripts` because that directory is reserved for script commands, which are deprecated (see link:{guidePath}commandLine.html#creatingCustomScripts[Creating Custom Scripts]).

=== Examples

[source,console]
----
// run a single script in the development environment
grails run-script scripts/helloWorld.groovy
// run multiple scripts in the production environment
grails run-script -Dgrails.env=production scripts/hello.groovy scripts/world.groovy
// run with Gradle
./gradlew runScript -Pargs="scripts/helloWorld.groovy" -Dgrails.env=production
----

The paths are resolved relative to the base project path

=== Description

Usage:

[source,console]
----
grails run-script [-Dname=value]... <<scripts>> [-- <<gradle arguments>>]
----

Arguments:

* `scripts` - Which scripts to run, in the order given

Variables:

The `ctx` variable is injected into all scripts and is an instance of the `ApplicationContext`

NOTE: Scripts are executed in the context of a persistent session. The default package is imported by default (`grails.codegen.defaultPackage`)

`run-script` runs the Gradle task `runScript` of the project with the files: the application is started around the scripts, without a web server, for the development environment or for the one `-Dgrails.env=NAME` names. A file is named by its path in the project or by its full path, and a name with spaces or quotes is the one file it is. A file that is not there is reported before Gradle is started. What follows `--` is given to Gradle as it is. See the user guide section on link:{guidePath}commandLine.html#gradleBuild[Building with Gradle] for the details.
