===== run-command



===== Purpose


Execute Grails Commands defined in `grails-app/commands` or in plugins.


===== Examples


[source,java]
----
grails run-command hello-world

./gradlew runCommand -Pargs="helloWorld"
----

The above scripts will expect `grails-app/commands/HelloWorldCommand.groovy` to exist in the application or in a plugin your application depends on.

`-Pargs` is split at spaces, with quotes read as a shell reads them. To give each argument exactly as it is, repeat `--arg`, the name of the command first:

[source,shell]
----
./gradlew runCommand --arg=hello-world --arg="an argument with spaces" --arg=--force
----

`--args-file=<file>` reads the arguments from a UTF-8 file that holds a JSON array of strings. See xref:commandLine#creatingCustomCommands[Creating Custom Commands] for both.


===== Description


Usage:
[source,java]
----
grails <<env>>* run-command <<command>>
----

Arguments:

* `command` - Which command to run
