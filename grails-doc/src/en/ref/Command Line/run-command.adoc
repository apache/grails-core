== run-command

`run-command` is the name link:run-tool.html[run-tool] had in Grails 8. It is another name of `run-tool`, deprecated: `grails run-command NAME` runs the tool `NAME` after one warning line, and the Gradle task `runCommand` runs it as `runTool` does, after a Gradle warning.

What Grails 8 called the commands of the application and its plugins are its _tools_ now; see link:{guidePath}commandLine.html#creatingTools[Creating Tools].
