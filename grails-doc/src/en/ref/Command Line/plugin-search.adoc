== plugin search

=== Purpose

Lists the Grails plugins that have a text in their name, their coordinates or their description: link:plugin-list.html[plugin list] with the text it lists by.

=== Examples

[source,console]
----
grails plugin search security
grails plugin search mongo --json
grails plugin search audit --deprecated
----

=== Description

Usage:

[source,console]
----
grails plugin search [--deprecated] [--offline] [--json] [--plugin-index=URL] FILTER
----

Arguments:

* `FILTER` - The text, which this command is not run without, one line of at most 100 characters. A plugin is listed when its name, its coordinates (`group:artifact`) or its description has the text, in whichever case.

`plugin search FILTER` writes what `plugin list FILTER` and `list-plugins FILTER` write, and takes their options: see link:list-plugins.html[list-plugins] for the options, the two lists the plugins come from, the plugin index and the JSON document of `--json`. Without a text the command is a mistake in the command line (exit code 2): `plugin list` lists every plugin. A text that no plugin has is no failure: the command says that no plugin has it and ends with exit code 0.

[source,console]
----
$ grails plugin search quartz --offline
Grails plugins for Grails 9.0.0
  Name    Coordinates                      Version  Description
  Quartz  org.apache.grails:grails-quartz  9.0.0    Schedules jobs that run at an interval or by a cron expression, with Quartz
1 plugin: 1 of this release of Grails, with the version the Grails BOM manages
More of one plugin: grails plugin show NAME
----

The plugin index of Grails records no labels for a plugin, so the text is looked for in the name, the coordinates and the description only.
