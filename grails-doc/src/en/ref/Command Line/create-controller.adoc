== create-controller

=== Purpose

The `create-controller` command creates a controller and associated unit test for the given base name.

=== Examples

[source,console]
----
grails create-controller Book
grails create-controller org.bookstore.Book
----

=== Description

Usage:

[source,console]
----
grails create-controller [-f] <<name>>
----

Creates a new controller with an empty default action: `grails-app/controllers/<package>/<Name>Controller.groovy`, and its test `src/test/groovy/<package>/<Name>ControllerSpec.groovy`. It is a command of every project.

A link:{guidePath}theWebLayer.html#controllers[controller] is responsible for handling incoming web requests and performing actions such as redirects, rendering views and so on.

The name is needed: the command does not ask for one. It can include a package, such as `org.bookstore` in the last example above; without one, the class goes into the default package of the project. The first letter of the name is made upper case.

Options:

* `-f`, `--force` - Replace a file that is there already. Without it the command writes nothing when one of its files exists, says which, and ends with exit code 1.

See "Creating Classes with the Grails Forge CLI" in link:{guidePath}commandLine.html[The Command Line] for the names the command takes, what it does when a file is there already, and how a project replaces the template.
