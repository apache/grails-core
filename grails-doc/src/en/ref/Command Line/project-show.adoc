== project show

=== Purpose

Says how the application in the current directory was generated: its type, name and package, its options, the features that were asked for and left out, and every feature it has.

=== Examples

[source,console]
----
grails project show
grails project show --json
----

=== Description

Usage:

[source,console]
----
grails project show [--json]
----

Options:

* `--json` - Write the record and the command as one JSON document for a tool to read.

`project show` is the `show` command of the `project` command. It reads the record of the project in its `.grails` directory. Its last line is the `create-` command that creates the application again, with the version of the command line that generated it.

Every option of the `create-` command is listed with the value the application was generated with, also an option that was not given, and marked: `default` when the value is what the running version of the command line takes when the option is not given, `differs from the current default: VALUE` when it is not, and `not recorded` when the record does not have it, in which case the current default is shown. The defaults of the `create-` commands can change from one version of Grails to the next; the record keeps the values, and the `create-` command in the last line has every option whose recorded value is not the current default. With `--json` the list is the member `effectiveOptions` (`name`, `option`, `value`, `default`, `status`) and the features that were not asked for are `addedFeatures`.

See "How a project was generated, and generating it again" in link:{guidePath}commandLine.html#creatingProject[Creating a Grails Project] for the output and the JSON document.
