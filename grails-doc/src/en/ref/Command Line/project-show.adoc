== project show

=== Purpose

Says how the application in the current directory was generated: its type, name and package, its options, the features that were asked for and left out, and every feature it has.

=== Examples

[source,console]
----
grails project show
grails project show --json
----

=== Description

Usage:

[source,console]
----
grails project show [--json]
----

Options:

* `--json` - Write the record and the command as one JSON document for a tool to read.

`project show` is the `show` command of the `project` command. It reads the record of the project in its `.grails` directory. Its last line is the `create-` command that creates the application again, with the version of the command line that generated it. For an application whose record link:project-migrate.html[project migrate] wrote, it says so, shows what the application is taken to be, and the last line is the command for a new application of the same type, options and features.

Every option of the `create-` command is listed with the value the application was generated with, also an option that was not given, and marked: `default` when the value is what the running version of the command line takes when the option is not given, `differs from the current default: VALUE` when it is not, and `not recorded` when the record does not have it, in which case the current default is shown. The defaults of the `create-` commands can change from one version of Grails to the next; the record keeps the values, and the `create-` command in the last line has every option whose recorded value is not the current default. With `--json` the list is the member `effectiveOptions` (`name`, `option`, `value`, `default`, `status`) and the features that were not asked for are `addedFeatures`.

The `build` line has the identity of the build of the generator that wrote the record, a SHA-256 digest that tells two snapshots of one version apart, and says whether it is the build of the command line that runs (`generator.sha256` with `--json`). A note says when the project is now on another version of Grails than the record, as after `grailsVersion` was changed by hand: the record says how the application was generated, and `project regenerate` and `feature add` are run by the command line of the version that generated it. See "The record over the life of a project" in link:{guidePath}commandLine.html#creatingProject[Creating a Grails Project].

For an application that was made from a preset, `project show` has a `preset` line with the name of the preset and the coordinates of its artifact, and the `create-` command has `--preset` with those coordinates; with `--json` the preset is the member `preset` (`name`, `coordinates`, `version`). See link:{guidePath}applicationTypes.html#presets[Making Applications from a Preset].

See "How a project was generated, and generating it again" in link:{guidePath}commandLine.html#creatingProject[Creating a Grails Project] for the output and the JSON document.
