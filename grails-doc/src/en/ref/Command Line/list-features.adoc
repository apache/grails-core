== --list-features

=== Purpose

Output the available features and their descriptions for a given `create-\<<application-type>>` command. Such as: `create-app`, `create-plugin`, `create-web-plugin`, `create-rest-api-plugin`, etc.

NOTE: The `--list-features` flag is an option of the commands that create a project.

=== Examples

[source,console]
----
$ grails create-app --list-features
----

=== Description

Usage:
[source,console]
----
$ grails create-app --list-features
$ grails create-plugin --list-features
----

Lists the features that are available for the type of application, by category. Typical output looks like this, where `...` stands for the categories that are left out here:

The options of the command that are given with `--list-features` decide the defaults the list marks, such as the Grails Data implementation of `--data`. A feature that no Grails BOM covers together with a feature the project has by default says so after its description, as `gorm-neo4j` does with `--data hibernate7`: `(cannot be combined with gorm-hibernate7: no Grails BOM covers both)`. The command refuses such a feature.
