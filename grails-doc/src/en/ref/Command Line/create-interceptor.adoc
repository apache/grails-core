== create-interceptor

=== Purpose

The `create-interceptor` command creates an interceptor and associated unit test for the given base name.

=== Examples

[source,console]
----
grails create-interceptor Book
grails create-interceptor org.bookstore.Book
----

=== Description

Usage:

[source,console]
----
grails create-interceptor [-f] <<name>>
----

Creates a new interceptor, `grails-app/controllers/<package>/<Name>Interceptor.groovy`, and its test `src/test/groovy/<package>/<Name>InterceptorSpec.groovy`. It is a command of every project.

An link:{guidePath}theWebLayer.html#interceptors[interceptor] is responsible for intercepting incoming web requests and performing actions such as authentication, logging and so on.

The name is needed: the command does not ask for one. It can include a package, such as `org.bookstore` in the last example above; without one, the class goes into the default package of the project. The first letter of the name is made upper case.

Options:

* `-f`, `--force` - Replace a file that is there already. Without it the command writes nothing when one of its files exists, says which, and ends with exit code 1.

See "Creating Classes with the `grails` Command" in link:{guidePath}commandLine.html[The Command Line] for the names the command takes, what it does when a file is there already, and how a project replaces the template.
