== create-domain-class

=== Purpose

The `create-domain-class` command creates a domain class and associated unit test for the given base name.

=== Examples

[source,console]
----
grails create-domain-class Book
grails create-domain-class org.bookstore.Book
----

=== Description

Usage:

[source,console]
----
grails create-domain-class [-f] <<name>>
----

Creates a domain class, `grails-app/domain/<package>/<Name>.groovy`, and its test `src/test/groovy/<package>/<Name>Spec.groovy`. It is a command of every project.

A domain class represents the core model behind your application and is typically mapped onto database tables. For more information on domain models in Grails refer to the chapter on link:{guidePath}GORM.html[GORM] in the user guide.

The name is needed: the command does not ask for one. It can include a package, such as `org.bookstore` in the last example above; without one, the class goes into the default package of the project. The first letter of the name is made upper case.

Options:

* `-f`, `--force` - Replace a file that is there already. Without it the command writes nothing when one of its files exists, says which, and ends with exit code 1.

See "Creating Classes with the `grails` Command" in link:{guidePath}commandLine.html[The Command Line] for the names the command takes, what it does when a file is there already, and how a project replaces the template.
