== dependency-report

=== Purpose

The `dependency-report` command prints the dependencies of the project.

=== Examples

[source,console]
----
grails dependency-report
grails dependency-report runtimeClasspath
----

=== Description

Usage:

[source,console]
----
grails dependency-report [-Dname=value]... [<<configuration>>] [-- <<gradle arguments>>]
----

Arguments:

* `configuration` - optional configuration to report on, for example `runtimeClasspath`. If omitted every configuration is reported.

`dependency-report` runs the Gradle task `dependencies`, and with a configuration `dependencies --configuration NAME`. What follows `--` is given to Gradle as it is. See the user guide section on link:{guidePath}commandLine.html#gradleBuild[Building with Gradle] for the details.
