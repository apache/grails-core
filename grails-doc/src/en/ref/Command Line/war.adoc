== war

=== Purpose

The `war` command creates the archive of the project for deployment. It is another name of link:assemble.html[assemble].

=== Examples

[source,console]
----
grails war
grails war --clean
grails war -Dgrails.env=staging
----

=== Description

Usage:

[source,console]
----
grails war [--clean] [-Dname=value]... [-- <<gradle arguments>>]
----

`war` runs the Gradle task `assemble` for the production environment. Another environment is given as `-Dgrails.env=NAME` after the command (`war -Dgrails.env=staging`); an environment in front of the command, as in `grails test war` of earlier versions, is refused. `--clean` runs `clean` first. What follows `--` is given to Gradle as it is. See the user guide section on link:{guidePath}commandLine.html#gradleBuild[Building with Gradle] for the details.

See link:assemble.html[assemble] for the archives the command creates.
