== create-integration-test

=== Purpose

The `create-integration-test` command creates an integration test for the given base name.

=== Examples

[source,console]
----
grails create-integration-test Book
grails create-integration-test org.bookstore.Book
----

=== Description

Usage:

[source,console]
----
grails create-integration-test [-f] <<name>>
----

Creates an integration test, `src/integration-test/groovy/<package>/<Name>Spec.groovy`, from the template `testing/Integration.groovy`. It is a command of web applications, REST API applications, web plugins and REST API plugins.

An integration test differs from a unit test in that the Grails environment is loaded for each test execution. Refer to the section on link:{guidePath}testing.html[Unit Testing] of the user guide for information on unit vs. integration testing.

The name is needed: the command does not ask for one. It can include a package, such as `org.bookstore` in the last example above; without one, the class goes into the default package of the project. The first letter of the name is made upper case.

Options:

* `-f`, `--force` - Replace a file that is there already. Without it the command writes nothing when one of its files exists, says which, and ends with exit code 1.

A name that ends with `Spec` already is taken without it.

See "Creating Classes with the `grails` Command" in link:{guidePath}commandLine.html[The Command Line] for the names the command takes, what it does when a file is there already, and how a project replaces the template.
